Para acessar o projeto SENAI Connect, abra o terminal do VS Code na pasta do projeto e execute o comando npm run start:all. Ele iniciará automaticamente o frontend e o backend, permitindo acessar o sistema pelo navegador. Certifique-se de que o MySQL esteja ativo para garantir a conexão com o banco de dados.

npm run start:all

npm run build
